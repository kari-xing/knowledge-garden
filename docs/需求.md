项目二："第二大脑"——AI知识花园
一、项目定位
一个融合笔记管理 + AI智能处理 + 知识图谱可视化的个人知识库系统。你把知识"种"进去，AI帮你浇水施肥——自动打标签、推荐关联、构建知识网络，让知识不再孤立，而是像花园一样自然生长。

核心差异化卖点：自动知识关联 + 动态知识图谱可视化 + "知识生命力"游戏化机制

七、核心算法/逻辑
间隔重复复习算法（艾宾浩斯变体）
python
REVIEW_INTERVALS = {
    1: 1,    # 第一次复习：1天后
    2: 3,    # 第二次复习：3天后
    3: 7,    # 第三次复习：7天后
    4: 15,   # 第四次复习：15天后
    5: 30,   # 第五次复习：30天后
}

def calculate_next_review(stage: int) -> date:
    if stage >= 5:
        return date.today() + timedelta(days=30)
    return date.today() + timedelta(days=REVIEW_INTERVALS[stage])
知识图谱关联更新策略
新增笔记时：计算与所有现有笔记的向量相似度，取Top 5，相似度>0.7时建立关联

每日定时：随机选取50篇笔记，计算两两相似度，发现新的潜在关联（用于发现已存在笔记间的隐藏关系）

关联理由生成：将两篇笔记的标题+摘要送入LLM，生成一句话关联理由
